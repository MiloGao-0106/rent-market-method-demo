# 租金市场法专业试用版

面向资产评估人员的 Excel 租金市场比较演示工具，覆盖资产识别、案例选用、逐因素修正、专项计租、内部复核和多版本成果导出。

**当前版本：V0.2。全部资产、案例、价格、合同、日期和依据编号均为模拟，不对应真实客户项目。计算检查通过不代表真实市场证据已核验，本工具不能直接作为正式评估结论。**

## 下载与开始使用

- [下载完整试用包](租金市场法专业试用包_V0.2.zip)：解压后保留各文件在同一目录。
- [查看详细使用手册](租金市场法专业试用版_详细使用手册_V0.2.docx)：14页，含操作步骤、计算规则、复算示例和异常练习。
- [下载完整版](租金市场法专业试用版_完整版_V0.2.xlsx)：作为维护输入和计算的主文件。
- [下载送审演示版](租金市场法专业试用版_送审演示版_V0.2.xlsx)：保留独立复算所需的12张工作表。
- [下载交流意见版](租金市场法专业试用版_交流意见版_V0.2.xlsx)：逐项结果快照，供填写确认意见。

GitHub不直接运行这些Office文件。打开相应文件页面后下载到本机，在Microsoft Excel或Word中使用。

## 主要功能

- 分列台账用途、实际状况、确认用途、物业形态、计租数量和面积属性。
- 检查重复案例编号、重复底层标的、重复网址和用途单位错配。
- 展示交易情况、日期、楼层、面积、装修等16项修正因素及其依据。
- 更换案例后提示重新判断评分，旧评分不自动继承。
- 区分按面积、按个、按间、按处和按场天计租，避免重复乘入面积。
- 计算历史最高最低离散、年度差异和B类金额占非设备年额比例。
- 从同一计算底座导出送审演示版与交流意见版，核对同批次逐项金额。

## 建议使用顺序

1. 另存一份练习副本，先阅读手册第2至4页。
2. 打开完整版，查看“专业总览”，核对“资产清单”和“计租与历史”。
3. 查看“市场案例库”“三案例选用”“修正明细”和“三案例测算”。
4. 按手册第8页复算RP-001，理解如何从案例原价形成最终单价和年租金。
5. 在副本执行手册第12至13页的异常练习，每次只改一项，观察后恢复。
6. 在“工时与反馈”填写实际工时、问题和使用反馈，不预填效率或盈利结论。

## 运行环境和同步导出

主要运行环境为安装了Microsoft Excel的Windows电脑；手册使用Microsoft Word阅读。较旧Excel及其他表格软件的公式与格式兼容性尚未验证。

修改输入后，在Excel保存并关闭完整版，再运行同目录的[同步导出.ps1](同步导出.ps1)。脚本调用本机Excel重新计算，更新两个外部版本并写入一致的导出批次；已有外部版本会先保存在“历史导出”目录。

脚本不上传文件、不采集网页、不请求账号密码。交流意见不会自动回写完整版，重新导出也不会自动合并旧意见，需要人工处理并留存记录。

## 计算与业务边界

- 20%单案例修正线、20%三案例极差线、10%B类比例及历史差异档位，均为本版沿用的项目内部规则，**不代表全国统一规范或法定限制**。
- `example.invalid`为无效占位域名，不是实际市场案例来源；`SIM-`编号表示模拟资料。
- 历史离散采用最高有效历史单价÷最低有效历史单价－1，不自动把当前结果限制在历史价格附近。
- 设备附表只接收独立的设备年租金结论，不含设备收益法、折旧或成本模型。
- 本版公式范围预设为20条资产。追加记录或改变路线需要同步扩展相关表格，不能只在末尾增加一行。
- 正式项目仍需核定范围、搜集并核验真实证据、论证可比性和修正依据，并由专业人员复核。
